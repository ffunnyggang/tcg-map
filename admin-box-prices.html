1. 가격표 등록

입력 방식

상품명·언어·구성·가격 단위(원/만원)를 명확히 입력해 주세요. 최대 20,000자.

선택한 판매처에 기존 가격이 등록된 상품만 조회합니다. 가격이 같아도 적용 체크 후 저장하면 업데이트됩니다. 삭제 시 선택한 판매처의 해당 상품 가격 등록이 제거됩니다.
