쿠폰 발급 관리

쿠폰함 보기 ↗

혜택과 사용 기간을 등록한 뒤 받을 회원을 선택해 발급하세요. 같은 쿠폰은 회원당 1장만 발급되며, 직원이 실물 교환을 확인한 후 사용 완료됩니다.

관리자 권한을 확인하고 있습니다.

1. 쿠폰 정보 등록

회원당 1장 · 중복 발급 불가
발급 취소도 총 발급 수량에 포함됩니다. 등록 후 혜택·기간은 고정되며, 변경하려면 새 쿠폰을 등록해주세요.

매장 직원이 고객의 쿠폰 사용 팝업에 입력할 코드입니다. 고객에게 안내하지 마세요. 저장 후 기존 코드는 조회할 수 없고 새 코드로 변경할 수 있습니다.

2. 회원 선택 · 쿠폰 발급

등록된 쿠폰을 선택해주세요.

신규 발급을 중지해도 이미 발급된 쿠폰은 기간 내 사용 가능합니다.

선택 0명 · 최대 0장 발급

3. 발급 이력

사용 완료 쿠폰은 취소할 수 없습니다. 취소된 쿠폰은 재발급되지 않습니다.

1페이지

쿠폰 발급 확인

확정하면 선택한 회원의 MY 쿠폰함에 표시되고 기존 쿠폰 발급 알림이 생성됩니다. 이미 발급한 회원은 건너뜁니다.

직원 확인코드 설정·변경

선택한 쿠폰에 공통으로 적용됩니다. 변경 즉시 기존 코드는 사용할 수 없습니다. 코드는 매장 직원에게만 공유해주세요.
