# FUNY PIN MARKET 1차 오픈 기준 및 Launch Gate

> 상태: **운영 제한 베타 (등록 허용계정제)**
>
> 운영 TCG MAP `/shops.html`에는 MARKET 조회 기능을 반영했다. 매물 조회는 일반 이용자에게 제공하되, **신규 매물 등록은 관리자 allowlist에서 허용한 FUNY PIN 계정만 가능**하다. 일반 판매자 등록 개방은 별도 승인 전까지 금지한다.
>
> 테스트 진입점 `/shops-market-test.html`은 QA 전용으로 유지한다.
> - 로그인 필수
> - `noindex,nofollow`
> - 운영 최신 MAP을 테스트 페이지로 덮어쓰지 않음
> - 운영은 `map-market-v1.js/css`, 테스트는 `map-market-test-v1.js/css`로 분리

## 1. 확정 서비스 컨셉

**“내가 이미 다른 플랫폼에 등록한 매물을 FUNY PIN 지도에도 연결하세요.”**

- FUNY PIN은 외부 플랫폼 매물의 추가 노출/연결 서비스다.
- FUNY PIN 내부에서 실제 거래·결제·배송·환불을 진행하지 않는다.
- 실제 거래는 원본 플랫폼(당근 / 번개장터 / BREAK)으로 이동해 진행한다.
- FUNY PIN 내부 거래 채팅은 1차 오픈에서 제공하지 않는다.
- 매물 등록은 **개인 판매자만** 가능하다.
- 사업자 또는 영업 목적 반복 판매자는 1차 오픈 대상이 아니다.

## 2. 외부 매물 수집 원칙

- 판매자가 본인의 외부 매물 URL을 직접 입력한 경우만 등록한다.
- FUNY PIN이 외부 플랫폼 전체 매물을 탐색·수집하는 크롤러를 운영하지 않는다.
- 자동 추출은 최초 등록 및 판매자가 직접 누르는 “정보 새로고침”에 사용한다.
- 등록된 활성 매물의 정보 최신성 유지를 위해 원본 상태(판매중/판매완료/삭제 등)를 제한적으로 재확인한다.
  - 유지관리 작업은 매시간 실행
  - 동일 매물은 최소 6시간 간격
  - 실행 1회당 최대 50건
- 외부 플랫폼 전체 매물을 탐색·수집하는 대량 크롤러는 운영하지 않는다.
- 수집 최소 범위:
  - 외부 매물 ID
  - 제목
  - 가격
  - 설명
  - 매물 이미지
  - 판매 상태
  - 원본 URL
  - 마지막 조회 시각
  - 외부 판매자 식별자(소유권 검증용, 공개하지 않음)
- 자동 복사하지 않는 정보:
  - 외부 판매자 닉네임
  - 외부 프로필 사진
  - 후기/평점/팔로워/매너온도
  - 정확한 외부 위치
  - 전화번호/계좌/채팅정보
- FUNY PIN 노출 정보는 FUNY PIN 계정 닉네임 + 사용자가 직접 선택한 거래 희망 위치를 사용한다.

## 13. Launch Gate

**아래 5개 그룹이 모두 완료되어야 PUBLIC OPEN 승인 가능**

1. 휴대폰 SMS 인증 + 외부 판매자 계정 소유 인증
2. 이용약관/개인정보/통신판매중개 법무 검토
3. 당근·번개장터·BREAK 데이터 이용/거래정책 검토
4. 신고·삭제·권리침해·분쟁 처리 체계
5. 정보 최신성/로그/보존 정책

현재 운영 반영은 **등록 허용계정 기반 제한 베타**이며 일반 판매자 PUBLIC OPEN으로 간주하지 않는다.
allowlist 없는 일반 회원의 등록 개방은 법무·외부 플랫폼 정책·iOS/AOS 실기기 QA 완료 후 별도 명시적 승인으로 진행한다.
