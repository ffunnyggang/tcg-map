1. 카드 사진 준비

저장된 한글·영문·일본판 카드에서 원본을 선택할 수 있어요. 로그인한 테스트 계정만 이용할 수 있으며, 불러오기는 AI 생성 횟수를 사용하지 않습니다.

일반적인 상단 사각 일러스트가 있는 포켓몬 카드만 지원합니다. 풀아트·점보·가로형은 지원하지 않습니다. 어두운 단색 배경에서 카드 한 장만 촬영해 주세요. 독립 배경 모드에서는 카드 사진을 서버에 전송하지 않습니다.

3. 확장 아트 만들기

일러스트로 참조 이미지 찾기 · 테스트

언어·카드명·번호는 비교하지 않습니다. 현재 지정한 일러스트 창만 비교해 후보를 찾습니다. 30th Celebration 영문 158종·Classic Collection 영문 30종·도감 한글 176종·일본 공식 167개 파일, 총 531개 참조 이미지를 사용합니다. 공식 목록에 없는 번호는 제외했고, LEGEND 두 카드는 합본 1개로 제공됩니다. 언어와 카드 번호가 달라도 같은 그림인지 비교하며, 후보는 직접 확인해 주세요. 제공된 원본 해상도로 저장합니다. 풀아트·가로형·트레이너·에너지 카드는 저장되어 있어도 현재 일반 프레임 확장 지원 대상은 아닙니다.

촬영 이미지 사용 중

AI 연결 상태를 확인하고 있어요.

DB 원본을 선택하면 이름·번호·언어를 자동 기록합니다. 촬영 사진은 카드 정보를 직접 입력해 주세요. 입력하지 않으면 카드 정보 미등록으로 저장됩니다.

원본 일러스트에서 캐릭터의 얼굴 중심을 지정합니다. 얼굴 이외의 그림은 AI에 전송됩니다.

미리보기에서 얼굴 중심을 선택하세요. 기본 위치는 그림의 가운데 위쪽이며 얼굴 크기는 직접 조절할 수 있습니다.

카드 전체 이미지를 외부 AI로 전송합니다. 요청한 풀아트 프롬프트를 사용하며, 참조 이미지 대체는 적용하지 않습니다. 글자·로고·캐릭터의 정확한 픽셀 보존은 보장되지 않습니다. 원본 결과는 절단선 없는 PNG로 제공하며, 아래 기존 출력 설정으로 절단선 PNG·A4 PDF도 저장할 수 있습니다. 도안 바깥 2mm 여백은 가장자리 픽셀을 연장합니다.

생성 후 저장된 노란색 30주년 심볼이 우측 하단에 자동 추가됩니다. 심볼을 따로 지정할 필요가 없으며, 합성된 결과가 저장·출력됩니다.

독립 배경은 선택한 테마만 전송하고 배경 전용 BETA는 경계 색상값 4개만 전송합니다. 두 방식 모두 카드 이미지는 외부 AI로 전송하지 않으며 기기에서 원본 그림을 합성합니다. 원본 기반 확장을 선택하면 일러스트가 외부 AI에 전송됩니다. 독립 배경은 원화의 연장이 아니며 형태가 이어지지 않을 수 있습니다.

이미 만든 확장 아트 불러오기

카드와 같은 비율이며 원본 그림 위치가 일치하는 이미지를 선택해 주세요.

생성에 성공한 이미지는 계정별로 비공개 저장됩니다. 촬영 원본은 별도 파일로 저장하지 않습니다. 생성 결과에 보존된 원본 그림·글자는 결과 이미지에 포함됩니다. 저장 상태를 확인해 주세요.
