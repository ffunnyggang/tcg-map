# TALK 바인더 독립 탭 및 보기 전환 스크롤 (2026-10-24)

- TALK ‘카드 자랑’ 바로 다음에 같은 기본 탭 스타일의 ‘바인더 자랑’을 추가한다. 기존 싱글·등급 카드 게시물은 ‘카드 자랑’에 그대로 남고 하위 2개 탭은 제거한다.
- 바인더 데이터는 기존 공개 publication 조회/차단·공유·자랑 멈추기 규칙을 유지한다. 일반 게시물 작성 카테고리(CATS)에 바인더를 추가하지 않아 DB에 잘못된 게시글 종류를 만들지 않는다.
- 저장된 v2 목록 상태 중 current=카드 자랑/showcaseTab=binders는 새 기본 탭으로 해석한다. 새 상태는 current만 저장하고 상세 복귀 시 탭/페이지/스크롤을 복원한다.
- 전체 탭의 인기 바인더 ‘더 보기’도 새 기본 탭으로 이동한다. 선택 탭이 가로로 가려진 경우 필터 줄만 수평으로 이동한다.
- 영어 라벨 Binder Showcase를 추가한다.

## 보기 모드 전환

- mode 변경 전 window x/y를 기록하고 렌더/다음 두 프레임에 복원한다.
- 긴 전체 보기 DOM을 비우거나 한 장 보기로 줄일 때 문서 높이가 부족해 브라우저가 스크롤을 0으로 당기는 것을 방지한다. 필요한 최소 높이만 일시 보장한다.
- 자연 콘텐츠 높이가 충분하거나 위로 스크롤한 경우 원래 body min-height로 복원하며, 화면 이탈 시에도 정리한다. 앱·웹의 상세 자랑 보기만 적용하고 편집 미리보기는 기존 동작을 유지한다.
- 사진 수가 많은 전체 보기의 전체 높이를 계속 유지하지 않는다. 불가피하게 현재 스크롤을 보장할 최소 공간만 남긴다.

## 검증

- 수정 전 binder.js를 주입해 전체→한 장에서 scrollY 102→0 실패를 재현했다.
- tests/binder-mode-scroll.cjs: 웹 및 app=1 시뮬레이션, 짧은/긴 문서, 전체→한 장 좌표 유지, 역방향, 가로 넘침 차단, 임시 높이 해제 통과.
- tests/talk-binder-tab.cjs: 기본 탭 순서, 카드/바인더 분리, 하위 탭 없음, 전체 레일 연결, 늦은 바인더 응답의 카드 목록 덮어쓰기 방지, 상세 복귀 탭·스크롤, 이전 상태 이전, 비로그인 안내를 격리 브라우저에서 확인한다.
- 기존 공유·목록 복원 단위 검사, inline script syntax, binder core/flip state 검사 통과. 책장 회귀 테스트의 바인더 탭 진입 경로도 갱신했다.
- 외부 네트워크는 차단하고 fixture 데이터만 사용했다. 운영 DB 변경 없음. 실기기 테스트가 아니며 웹 배포로 적용한다.
