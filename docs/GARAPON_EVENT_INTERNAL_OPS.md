# FUNY PIN 이벤트용 가라폰 — 내부 운영 점검

## 목적

이 문서는 이벤트용 가라폰과 퍼니코인 기능을 고객에게 공개하기 전에 관리자·테스터 범위에서 구현하고 검증하기 위한 운영 기준입니다.

현재 고객 노출 요소는 추가하지 않습니다.

- HOME, TCG MAP, PICK, TALK, MY, TCG TOOL에 진입 링크를 추가하지 않습니다.
- 이벤트용 가라폰 페이지와 내부 운영 화면은 검색엔진 색인을 차단합니다.
- 일반 회원은 비공개 URL을 직접 입력해도 서버 RPC에서 차단됩니다.
- 출시 잠금이 유지되는 동안 이벤트 공개, 퍼니코인 공개, 회원가입 보너스 지급은 활성화할 수 없습니다.
- 출시 잠금 중 생성·수정되는 이벤트는 서버가 `visibility = test`로 강제 저장합니다.

## 내부 화면

### 이벤트 관리

`/admin-garapon-event-test.html`

- 이벤트 생성·수정
- 구슬·상품 구성
- 참여 비용과 제한 설정
- 테스트 계정 등록
- 퍼니코인 수동 지급·회수
- 참여·대기·당첨 처리

### 운영 점검

`/admin-garapon-ops-test.html`

- 출시 잠금 상태 확인
- 이벤트·컬러별 구슬 재고 정합성 점검
- 공유 대기열 시간 연속성 점검
- 공개 시각이 지난 미마감 참여 확인
- 당첨 결과와 클레임 생성 여부 점검
- 회원별 진행 중 중복 참여 확인
- 퍼니코인 지갑과 최종 원장 잔액 대조
- 공개 완료 당첨과 MY 응모 내역 대조
- 자동 마감 cron 상태 확인
- 이벤트, 테스터, 코인 원장, 감사 로그 CSV 내보내기
- 공개 시각 경과 결과 수동 마감
- 선택 이벤트의 공개 전 대기열 수동 재정렬

운영 점검 페이지는 `admin_get_garapon_ops`와 `admin_run_garapon_maintenance` 관리자 전용 RPC만 사용합니다. 공개 설정을 변경하는 기능은 포함하지 않습니다.

## 서버 진단 항목

| 키 | 점검 내용 | 정상 기준 |
|---|---|---|
| `release_lock` | 가라폰·코인·가입 보너스 공개 상태 | 두 출시 잠금 ON, 공개 설정 OFF |
| `inventory` | 이벤트 재고와 구슬별 합계 | 총수량·남은수량 모두 일치 |
| `queue` | 대기열 순번별 시간 | 이전 공개 시각과 다음 시작 시각이 연속 |
| `overdue` | 공개 지연 참여 | 공개 시각 90초 초과 대기 0건 |
| `claims` | 당첨 결과와 클레임 | 당첨에만 클레임 존재 |
| `duplicates` | 진행 중 중복 참여 | 이벤트·회원별 1건 이하 |
| `wallets` | 지갑과 코인 원장 | 지갑 잔액과 마지막 원장 잔액 일치 |
| `entries` | MY 당첨 내역 | 공개 완료 당첨에 응모 내역 존재 |
| `public_events` | 잠금 중 공개 이벤트 | 0건 |
| `cron` | 자동 결과 마감 | 작업 활성화 및 최근 실행 성공 |

## 수동 운영 작업

### 결과 마감 실행

공개 시각이 지난 `queued` 참여를 `completed`로 전환하고, 당첨 클레임과 MY 응모 내역을 확정합니다. 전체 이벤트 또는 선택 이벤트 기준으로 실행할 수 있습니다.

### 대기열 재정렬

선택 이벤트의 공개 전 대기열만 현재 시각부터 이벤트의 `turn_seconds` 간격으로 다시 정렬합니다. 진행 중 사용자의 표시 시간이 변경될 수 있으므로 대기열 장애나 관리자 환불 이후에만 사용합니다.

모든 수동 작업은 `garapon_admin_audit_logs`에 기록됩니다.

## 공개 전 필수 조건

1. 서버 자동 진단 전 항목 정상
2. 실기기 Web, iOS WebView, Android WebView 동시 참여 검증
3. 여러 계정 동시 요청·재시도·네트워크 중단 검증
4. 이벤트 상품 수량과 서버 구슬 수량 대조
5. 당첨자 Instagram ID 수집·보관·삭제 정책 확정
6. 퍼니코인 획득·사용·환불 운영 정책 확정
7. 고객 안내 문구와 이용약관 검토
8. 앱 배포 버전에서 MY 당첨 처리 검증
9. 관리자 최종 공개 승인
10. 별도의 출시 잠금 해제 마이그레이션 적용

위 조건을 모두 충족하기 전에는 `garapon_feature_settings.release_locked`와 `funy_coin_settings.release_locked`를 `true`로 유지합니다.
