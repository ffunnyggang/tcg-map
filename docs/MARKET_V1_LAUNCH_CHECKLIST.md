# FUNY PIN MARKET 1차 오픈 기준 및 Launch Gate

> 상태: **비공개 테스트 전용**
>
> **중요:** 아래 P0 항목이 모두 완료되기 전에는 운영 `shops.html`, HOME, PICK, TALK, MY, 운영 내비게이션, 공개 CMS/배너/팝업 어디에도 MARKET/거래 링크·탭·버튼을 연결하지 않는다.
>
> 테스트 진입점: `/shops-market-test.html`
> - 로그인 필수
> - `noindex,nofollow`
> - 운영 TCG MAP과 분리
> - MARKET runtime은 `/shops-market-test.html` 이외 경로에서 실행 금지

## 1. 확정 서비스 컨셉

**“내가 이미 다른 플랫폼에 등록한 매물을 FUNY PIN 지도에도 연결하세요.”**

- FUNY PIN은 외부 플랫폼 매물의 추가 노출/연결 서비스다.
- FUNY PIN 내부에서 실제 거래·결제·배송·환불을 진행하지 않는다.
- 실제 거래는 원본 플랫폼(당근 / 번개장터 / BREAK)으로 이동해 진행한다.
- FUNY PIN 내부 거래 채팅은 1차 오픈에서 제공하지 않는다.
- 매물 등록은 **개인 판매자만** 가능하다.
- 사업자 또는 영업 목적 반복 판매자는 1차 오픈 대상이 아니다.

## 2. 외부 매물 수집 원칙

- 판매자가 본인의 외부 매물 URL을 직접 입력한 경우만 등록한다.
- FUNY PIN이 외부 플랫폼 전체 매물을 탐색·수집하는 크롤러를 운영하지 않는다.
- 자동 추출은:
  1. 최초 등록 시 1회
  2. 판매자가 직접 누르는 “정보 새로고침”
  로 제한한다.
- 주기적/백그라운드 대량 크롤링은 하지 않는다.
- 수집 최소 범위:
  - 외부 매물 ID
  - 제목
  - 가격
  - 설명
  - 매물 이미지
  - 판매 상태
  - 원본 URL
  - 마지막 조회 시각
  - 외부 판매자 식별자(소유권 검증용, 공개하지 않음)
- 자동 복사하지 않는 정보:
  - 외부 판매자 닉네임
  - 외부 프로필 사진
  - 후기/평점/팔로워/매너온도
  - 정확한 외부 위치
  - 전화번호/계좌/채팅정보
- FUNY PIN 노출 정보는 FUNY PIN 계정 닉네임 + 사용자가 직접 선택한 거래 희망 위치를 사용한다.

## 3. 판매자 인증

### P0 — PASS 본인확인
- [ ] 최초 매물 등록 전 PASS/NICE/KCB 등 본인확인 연동
- [ ] 계정당 최초 1회 인증
- [ ] 인증 완료 여부 및 법적 대응에 필요한 최소 정보만 별도 보관
- [ ] 개인정보 최소수집/암호화/보관기간 확정
- [ ] 본인확인 업체 개인정보 처리위탁 사항을 개인정보처리방침에 반영

### P0 — 외부 플랫폼 계정 소유 확인
- [ ] 플랫폼별 최초 외부 판매자 계정 인증
- [ ] 인증코드를 본인 외부 매물 설명에 임시 기재
- [ ] FUNY PIN 서버 재조회로 인증코드 확인
- [ ] 성공 시 `provider + external_seller_id + FUNY PIN user_id` 연결
- [ ] `provider + external_seller_id` UNIQUE 처리
- [ ] 동일 외부 계정이 다른 FUNY PIN 계정에 중복 연결되지 않도록 차단
- [ ] 인증된 외부 계정의 추가 매물은 seller ID 일치 시 재인증 생략
- [ ] 외부 seller ID가 안정적으로 확인되지 않는 플랫폼은 매물별 인증 유지

플랫폼별 현재 판단:
- 번개장터: 고유 `uid` 확인 가능 → 계정 1회 인증 구조 적용 가능
- 당근: 안정적인 프로필 식별자 추가 검증 필요
- BREAK: 불변 seller ID 추가 확인 전까지 매물별 인증 유지

## 13. Launch Gate

**아래 5개 그룹이 모두 완료되어야 PUBLIC OPEN 승인 가능**

1. PASS + 외부 판매자 계정 소유 인증
2. 이용약관/개인정보/통신판매중개 법무 검토
3. 당근·번개장터·BREAK 데이터 이용/거래정책 검토
4. 신고·삭제·권리침해·분쟁 처리 체계
5. 정보 최신성/로그/보존 정책

PUBLIC OPEN은 별도 명시적 승인 작업으로 진행한다.
테스트 기능 구현 완료나 `main` 웹 배포는 PUBLIC OPEN 승인으로 간주하지 않는다.
