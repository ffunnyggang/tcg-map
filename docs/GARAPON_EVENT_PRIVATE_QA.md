# FUNY PIN 가라폰 이벤트 — 비공개 개발·QA 기준

## 현재 공개 상태

- 기존 TCG TOOL `garapon.html`은 그대로 유지한다.
- 이벤트용 기능은 아래 비공개 경로에서만 검증한다.
  - 사용자: `/garapon-event-test.html?event=<EVENT_ID>`
  - 관리자: `/admin-garapon-event-test.html`
  - 퍼니코인 지갑: `/my-funy-coin-test.html`
- 위 경로는 검색엔진 색인을 차단한다.
- HOME / PICK / TCG TOOL / MY 메뉴 / CMS에는 비공개 경로를 연결하지 않는다.
- `garapon_feature_settings.public_enabled`는 `false`를 유지한다.
- `funy_coin_settings.system_enabled`와 `signup_bonus_enabled`는 `false`를 유지한다.
- 양쪽 설정의 `release_locked`는 출시 승인 전까지 `true`를 유지한다.
- 비공개 이벤트는 `visibility='test'`만 허용한다.
- 관리자 또는 `garapon_testers`에 등록된 회원만 접근할 수 있다.

## 출시 전 필수 승인 조건

1. 서버 추첨·재고·퍼니코인 트랜잭션 검증 완료
2. 동시 참여 및 대기열 부하 테스트 완료
3. 실패·취소·환불 복구 테스트 완료
4. 웹 / iOS WebView / Android WebView 화면 QA 완료
5. MY 응모 내역과 Instagram ID 제출 QA 완료
6. 관리자 상품 처리 상태 및 감사 로그 QA 완료
7. 비로그인·비테스터·일반 회원 접근 차단 확인
8. 회원가입 보너스 중복 지급 및 탈퇴·재가입 악용 정책 확정
9. 운영약관·개인정보 처리 안내·이벤트 유의사항 반영
10. 운영자 최종 공개 승인

## 핵심 보안 원칙

- 추첨 결과는 브라우저에서 계산하지 않는다.
- 결과와 구슬 재고는 서버 트랜잭션 안에서 함께 확정한다.
- 퍼니코인 차감과 참여 생성은 하나의 트랜잭션으로 처리한다.
- 같은 요청의 재전송은 idempotency key로 중복 차감하지 않는다.
- 결과 공개 시각 전에는 사용자 응답에 결과를 포함하지 않는다.
- 인스타그램 ID는 본인과 관리자만 확인한다.
- 관리자가 설정을 바꾸거나 보상을 처리하면 감사 로그를 남긴다.
- 공개 플래그는 DB release lock을 해제하기 전에는 켤 수 없다.

## 자동 검증 항목

- hidden 페이지 `noindex` 적용
- 공개 진입 화면에 hidden URL 미노출
- 사용자 클라이언트에 로컬 추첨 코드 미포함
- 공개·회원가입 보너스 스위치 강제 OFF
- Web Auth 저장소 정리 함수 무한 재귀 방지
- JavaScript / TypeScript 문법 및 빌드 검사

## 서버 회귀 테스트

- 이벤트 생성, 구슬 설정, 활성화
- 비테스터 `feature_hidden`
- 퍼니코인 부족 차단
- 동일 idempotency key 중복 참여·중복 차감 방지
- 동일 사용자의 진행 중 중복 참여 차단
- 두 사용자 대기열 순번·시간 직렬화
- 공개 전 결과 마스킹
- 공개 후 결과 및 MY 당첨 내역 생성
- Instagram ID 제출
- 관리자 확인·DM 발송·전달 완료 상태
- 관리자 환불 시 퍼니코인 및 구슬 재고 복구
- 환불 후 남은 대기열 시간 재정렬
- 암호학적 난수 범위 검증
- release lock 우회 시도 차단

## 수동 QA 이벤트

- 제목: `[QA] 가라폰 이벤트 비공개 검증`
- 공개 범위: `test`
- 사용자 페이지는 관리자 화면에서 복사한 비공개 URL로만 진입한다.
- QA 종료 후 이벤트는 `ended` 또는 `cancelled`로 전환하고, 필요 시 테스트 참여·코인 내역을 별도 정리한다.

## 공개 전환 절차

1. QA 이벤트 종료
2. 운영 이벤트 최종 설정 및 상품 재고 대조
3. 운영약관·개인정보 안내 반영
4. 앱 배포가 필요한 MY 네이티브 변경 승인·배포
5. DB 백업 및 운영 점검
6. `release_locked` 해제용 별도 승인 마이그레이션 실행
7. 퍼니코인 시스템 활성화
8. 회원가입 지급 활성화
9. 가라폰 공개 플래그 활성화
10. HOME / PICK / MY 등 실제 사용자 진입점 연결

공개 전환은 위 순서를 따르는 별도 작업으로 진행하며, 비공개 QA 단계에서 공개 플래그를 직접 변경하지 않는다.
